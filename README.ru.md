# tt-obstacle — версия 0.1.0

Исследовательский репозиторий о сохранении допустимости при TT-сжатии
решений дискретных obstacle-задач. Здесь собраны работающий пакет Python,
теоретические записки, тесты, примеры и ограничения подхода.

Если исходный тензор удовлетворяет `U >= psi`, обычное TT-округление `V`
может нарушить это неравенство. Строим оболочку `E >= |U - V|` и получаем
`W = V + E >= U >= psi`. Это и означает **feasibility preserving**:
сохранение ограничения на препятствие после сжатия.

В пакете есть квадратичная поправка и поправки ранга один, операции над
TT-ядрами, согласованные Q1-энергии и проекторы на порядок взаимодействий.
Гарантии в точной арифметике отделены от проверок с плавающей точкой.
Равномерная энергетическая оценка требует структурных условий; одного
малого TT-ранга недостаточно.

## Запуск

Из корня распакованного проекта, Python 3.10+:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install .
python examples/compression_and_repair.py
python -m unittest discover -s tests -v
```

В Windows PowerShell активация: `.venv\Scripts\Activate.ps1`.

В малом примере обычное сжатие нарушает препятствие. Обе поправки устраняют
нарушение в численной проверке. Одна уменьшает число хранимых коэффициентов
с 18 до 12; другая использует 72 коэффициента при несколько меньшей ошибке.
Экономия памяти не гарантируется.

Это инструменты аппроксимации и восстановления допустимости. Эталонный
obstacle-решатель перебирает активные множества и предназначен только для
малых задач. Полного эффективного многомерного PDE-решателя здесь пока нет.
